Conhecendo o Bootstrap

Versão Utilizada: 5.3

O que é?

O Bootstrap é um poderoso framework front-end de código aberto. Ele fornece uma coleção gigante de componentes CSS e JavaScript pré-construídos para estilizar botões, formulários, cartões, menus e estruturar layouts completos.

Para que serve?

Ele acelera o desenvolvimento web. Em vez de escrever todo o CSS do zero para alinhar caixas ou criar um menu que funciona no celular, aplica-se classes específicas no HTML (ex: class="btn btn-danger"), e o Bootstrap cuida do estilo e comportamento.

Sistema de Grid e Responsividade

A base do layout do Bootstrap é o Grid System. Ele divide a largura da tela em 12 colunas flexíveis.

Design Responsivo:

Ajusta-se a qualquer tamanho de tela (celular, tablet e computador) através de prefixos de breakpoint:

.col-12 (Celulares)
Ocupa 100% de largura. Os elementos ficam empilhados.
.col-md-6 (Tablets)
Ocupa 50% de largura (2 elementos por linha).
.col-lg-4 (Monitores)
Ocupa 33.3% de largura (3 elementos por linha).

Neste projeto, as colunas dos carros usam:

<div class="col-12 col-md-6 col-lg-4">

Componentes Utilizados Neste Projeto

.navbar
1. Navbar (Barra de Navegação)

Permite a troca rápida de páginas e contrai para menu hambúrguer em telas menores.

.card
2. Cards (Cartões)

Utilizados na Garagem para destacar as imagens, preços e botões de compra.

.modal
3. Modals (Janelas Flutuantes)

Usados para o checkout de pagamento, confirmação de compra e exibição de detalhes dos veículos.

.offcanvas
4. Offcanvas (Menu Lateral / Carrinho)

Painel deslizante usado para exibir os itens do carrinho de compras.

.badge & .btn
5. Botões e Insígnias

Classes estilizadas para botões de ação e contadores de itens no carrinho.
